核心能力

三行代码管理项目群，不依赖任何 LLM

📊

进度记录（按分支）

每个分支做到哪、停滞多久、是否已合并。Conventional Commits 自动分类，工程脉搏一目了然。

📝

浅更新文档

把各分支进度写进 README / AGENTS / CLAUDE 的托管区域。非托管内容逐字节保留。

🏗️

深度更新

基于全量历史重写 overview / architecture / commands / history 四大章节。

🌿

Git 集成

worktree / stash / untracked / merge-base 全感知。面板级白名单操作（pull / push / commit），零破坏性。

🚩

里程碑

绑定 git tag 自动判定达成。目标日期逾期计算。跨项目聚合仪表盘。

🤖

Agent 三件套

CLI --json / MCP 服务器（15 工具）/ Skill 教学包。任何 AI agent 均可接入，引擎不感知 AI。

架构

AI 无关内核 + 上层 AI 实现分离（deepDesign 模式）

🤖 AI 层（deepDolphin 等客户端）

models.dev 目录选型 · ai-sdk 风格通道 · 原生 tool_calls · 提示词组装 · 密钥存储（本机钥匙串）

⚙️ moonGit Engine（本仓库）

git 采集 · 进度库 · 文档托管写入 · 规则引擎 · CLI --json · MCP 服务器 · HTTP API

唯一耦合面 = HTTP / CLI 的 JSON 键名。引擎不感知任何客户端，客户端不做任何业务计算。

安装

macOS ARM64 · Linux x64（更多平台规划中）

# 从 Release 下载 curl -fsSL "https://github.com/asdshuaishuai/moongit/releases/latest/download/moongit-darwin-arm64.tar.gz" -o moongit.tar.gz tar xzf moongit.tar.gz mv moongit-cli ~/.local/bin/moongit && chmod +x ~/.local/bin/moongit # 注册项目群 moongit scan ~/dev --depth 4 # 看现状 moongit status

完整安装请用 sh scripts/install.sh（自动处理 macOS 26+ SDK 兼容、安装到 PATH、可选钩子）。

Agent 接入

CLI / MCP / Skill 三件套，同源同权

方式用途接入
CLI一次性问答、脚本moongit status --json
MCP工具化接入（推荐）moongit mcp（stdio JSON-RPC，15 工具）
Skill编码类 agent 教学moongit skill install
HTTP本地服务moongit serve → GET /api/*

任何 MCP 宿主（Claude、其它 agent）一行接入；引擎只提供事实与动作，判断与表达由 agent 完成。

红线

🔒 git 操作白名单

pull / push / commit / stash / unstash / fetch。没有 reset / clean / force-push。

📝 托管区域写入

只改写 moonGit 标记的区域，用户内容逐字节保留，写入前自动备份。

🔒 AI 无关

引擎零 LLM 调用、零密钥存储。AI 层在客户端，密钥在钥匙串。
